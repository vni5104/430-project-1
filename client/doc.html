Books API Documentation

Get Book

Relative URL: /getBook

Query Params

title [type: text, required]

Returns

A JSON object (or JSON objects if there are more than one object with the same title)

Format {author:"", country:"", language:"", link:"", pages:"", title:"", year:"", genres:[""]}

Example

Request: /getBook?title=Fairy%20tales
Result: {"author":"Hans Christian Andersen","country":"Denmark","language":"Danish", "link":"https://en.wikipedia.org/wiki/Fairy_Tales_Told_for_Children._First_Collection.\n", "pages":784,"title":"Fairy tales","year":1836,"genres":["Fairy Tales","Children's Literature"]}

Get Authors

Relative URL: /getAuthors

Query Params

country [type: text, required if other param(s) is not provided]

language [type: text, required if other param(s) is not provided]

Returns

A JSON object holding a list of author names (without duplicates)

Format ["name1", "name2"]

Example

Request: /getAuthors?country=United%20Kingdom
Result: ["Jane Austen","Emily Brontë", "Joseph Conrad","Charles Dickens","George Eliot","D. H. Lawrence","Doris Lessing", "George Orwell","Virginia Woolf"]

Add Book

Relative URL: /addBook

author [type: text, required]

country [type: text, optional]

language [type: text, optional]

link [type: text, optional]

pages [type: number, optional]

title [type: text, required]

Text with status code and message, and JSON book object if created (not updated)
